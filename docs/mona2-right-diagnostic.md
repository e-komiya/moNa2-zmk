# moNa2右手 診断ファームウェア

この診断版は、右手moNa2の通常キーマップ・コンボ・ホールドタップを使わず、マトリクスの各位置を単純なキーコードへ割り当てる。D3/P0.29行の右手6位置は、左から順に `1`〜`6` として出力する。N位置は `1` になる。

## ビルド

GitHubの `Build moNa2 right diagnostic firmware` ワークフローを `Run workflow` で実行する。完了後、`mona2-right-diagnostic` アーティファクト内の `mona2_r_diagnostic.uf2` をXIAO nRF52840へコピーする。

## 判定

1. USB接続し、通常のキー履歴またはキーテスターを開く。
2. D3/P0.29行のN位置を押す。`1` が出れば、ダイオード→行配線→XIAOのGPIO入力→ZMKスキャンまで到達している。
3. `1` が出ず、同じ行の他位置（`2`〜`6`）が出る場合は、N列側のソケット・ダイオード・列配線を調べる。
4. D3行の `1`〜`6` がすべて出ない場合は、D3/P0.29のXIAO接合またはXIAO GPIOを疑う。

## USBログ

このビルドはUSB CDC ACMログも有効にする。Windowsのデバイスマネージャーで新しく現れるCOMポートを確認し、115200 baud・8-N-1でシリアル端末を開く。キーを押したとき、`kscan_matrix_read` の `row`・`col`・`state on/off` が出れば、キーコード変換前の生スキャンイベントを確認できる。N位置では `row 2, col 6`（0始まり）が期待値である。

## 注意

診断版を書き込む前に、既存UF2を保存しておく。通電中にテスターの抵抗・導通モードで測定したり、GPIOを3.3V/GNDへ直結したりしない。
