# moNa2 model files

This directory contains the model files used for the current moNa2 build.

- Files directly under `model/` are local print projects or derived models.
- Files under `model/original/` are unmodified source files fetched from the
  upstream moNa2 repository.

The local `case-2.3mf` and the upstream `original/case/case-2.3mf` intentionally
have the same filename but different contents. Keep both files in their current
locations so the edited print project is not confused with its source data.

See `original/README.md` for the upstream source and revision.
