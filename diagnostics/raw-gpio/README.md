# moNa2右手：GPIO直接読取り診断 v1

対象は通常型Seeed XIAO nRF52840を搭載した右手moNa2。ファイル名は`mona2-right-raw-gpio-v1.uf2`。左手や別型番のマイコンには書き込まない。実機検証は利用者の測定が必要。

## 何を測るか

通常キーボード処理を含まない独立したZephyrアプリ。USBシリアルだけを使用し、HID・Bluetooth・トラックボール処理・ZMKの行列スキャンは動かさない。キーを押してもメモ帳に文字が出ないのが正常。

`s`をシリアルに送るとD10/P1.15をHIGH出力にし、XIAO内部GPIO入力値を250ms間隔で表示する。通常の高速走査ではなく、1列を一定状態にする。起動直後は列出力を高インピーダンスとし、`x`、開始から60秒、またはアプリがDTR解除を検出した場合に駆動を停止する。これは故障した回路の過電流を保証して防ぐ機能ではない。

| 表示 | 読取り対象 | 通常の期待値 |
|---|---|---|
| COL_D10 | XIAO D10/P1.15のチップ側入力 | ACTIVE中は1 |
| H_D2 | XIAO D2/P0.28 | Nの真上の物理キー（通常配列H）を押すと1 |
| N_D3 | XIAO D3/P0.29 | 物理Nを押すと1 |
| ROW0_D1 | XIAO D1/P0.03 | 同じ列の上段（通常配列Y）を押すと1 |
| ROW3_D6 | XIAO D6/P1.11 | 対象列の第4行入力 |

ここでD3はXIAOの端子名。メイン基板上のダイオードD3とは別。USB端子を上、銀色シールド面を手前にすると、XIAO D3は左列上から4番目、D10は右列上から4番目。

## 事前準備と書込み

1. 復帰用の右手ファームUF2を手元に保存しておく。`settings_reset`は不要。診断アプリは設定消去処理を行わないが、設定保持・復帰の実機確認は別途必要。
2. USB・バッテリーを外して、基板を乾いた非導電面に固定する。浮いた導線が隣接端子や金属面に触れないようにする。バッテリーは接続せず、以降はUSBだけを使う。通電中に線を付け外ししない。
3. 右側XIAOをUSBに接続し、リセットを素早く2回押す。エクスプローラーに現れたUF2書込みドライブへ`mona2-right-raw-gpio-v1.uf2`だけをコピーする。
4. 再起動でドライブが消えたあと、COMポートを開く。コピー時のエラーやドライブ消失だけでは成功と判定しない。下記の固有表示を確認する。

電力サージ警告、異常発熱、においが出た場合はUSBを抜いて中止する。通電中の抵抗・導通・ダイオード測定や、信号端子の電源/GNDへの直結は行わない。

## Tabbyなどで開く

- Windowsのデバイスマネージャー →「ポート（COMとLPT）」で、このXIAOのCOM番号を確認する。キーボード用ファーム時と番号が変わる場合がある。
- シリアル接続でそのCOMを指定。115200 baud、8 data bits、parity none、1 stop bit、flow control none。DTRを有効にする。
- 他のシリアルソフトは同じポートを閉じる。
- 接続直後の識別表示、または約2秒ごとの次の行を確認する。

```text
MONA2-RAW-GPIO-v1 IDLE; send s to start (x to stop)
```

この表示がなければ、まだキー試験へ進まない。COM番号・DTR・書き込んだUF2を確認する。何も表示されなくてもGPIOへ配線を追加しない。

## 最初はNだけを試す

1. 別の正常なキーボードから、シリアル端末内で半角小文字`s`を送信する。必要ならEnterも押す。改行は無視される。
2. `ACTIVE: D10 HIGH...`が出ることを確認する。`PIN_CNF28`と`PIN_CNF29`はどちらも`00000004`が期待値。
3. どのキーも押さず2秒待つ。
4. 物理Nを軽く押して2秒保持し、離して2秒待つ。Nは通常のHの真下にある下段キーで、XIAO直下の内側追加キーではない。
5. 半角`x`をシリアルへ送って停止する。押す前・押している間・離した後のログを保存する。

正常な場合の表示例。実測ログではない。

```text
RAW ACTIVE COL_D10=1 H_D2=0 N_D3=0 ROW0_D1=0 ROW3_D6=0
RAW ACTIVE COL_D10=1 H_D2=0 N_D3=1 ROW0_D1=0 ROW3_D6=0
RAW ACTIVE COL_D10=1 H_D2=0 N_D3=0 ROW0_D1=0 ROW3_D6=0
```

60秒で停止したら、必要時にもう一度`s`を送る。ACTIVE中に`s`を再送しても時間は延長されない。

M・,・.・/の列は駆動しないため、この診断でそれらが反応しなくても故障判定をしない。

## 結果の読み方

- N_D3が押下で1、解放で0：この定常条件では入力がXIAO内部まで届いている。通常スキャン条件との差を調べる。
- N_D3がずっと0：それだけでは接合かチップかを断定しない。比較用のNの真上の物理キーと、必要に応じた外部電圧測定で切り分ける。
- N_D3がずっと1：キーを離した状態の異常な接続・負荷・入力状態を調べる。
- Nを押した際にCOL_D10が0になる：列電圧が下がる異常を疑う材料。試験を停止してログを確認する。

GPIOの0/1は電流や実際の電圧値ではなく、チップが入力電圧を論理値として読んだ結果。COL_D10もチップ側の値なので、外部パッドへ確実につながっていることまでは証明しない。

## 復帰

`x`で停止し、シリアル接続を閉じる。リセットを素早く2回押してUF2ドライブを出し、保存した右手用ファームをコピーする。USBを抜き差しし、通常の動作を確認する。

## ビルドと出典

リポジトリの`Build keyboards`ワークフローで`raw_gpio=true`を指定する。このモードでは通常キーボード6構成のビルドを実行しない。

ZephyrはZMK 0.3系の`dacab4875df72109b96cc8977547a0dc04875bcd`に固定。ボードは`seeeduino_xiao_ble`。生成`.config`・devicetree・ELF・依存関係・UF2ハッシュを成果物へ含める。
