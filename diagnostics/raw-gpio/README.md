# moNa2右手 総合GPIO診断 v3

右手のSeeed XIAO nRF52840へ一度だけ書き込み、USBシリアルから条件を切り替えて行列の生GPIOを比較する診断ファームウェアです。通常のZMK/HID/BLE/トラックボールは動かず、文字が入力されないのが正常です。診断中はバッテリーを外し、USBだけを使います。

## 書き込み

成果物の`mona2-right-diag-v3.uf2`を保存し、右手XIAOをリセット2回でUF2ドライブにしてコピーします。ドライブが消えたらCOMポートを115200/8-N-1/flow control none、DTR有効で開きます。起動表示が`MONA2-DIAG-v3 READY`であることを確認してください。コピー時の「デバイスが存在しない」は再起動でドライブが消えた結果なら正常です。

## コマンド

`?` メニュー、`i` GPIO入力/出力/PIN_CNFとNFC設定、`a` ADC欄（この版はGPIO安全性を優先し外部DMMで電圧を測る案内のみ）、`0`〜`4` 列選択、`s` 選択列HIGH・他列Hi-Z、`l` 選択列HIGH・他列LOW、`f` 全列走査（待ち時間0）、`m` 走査（100us）、`t` 走査（1000us）、`z` 全列走査（非選択列Hi-Z）、`b` 6条件を各5秒で自動巡回、`x` 即時停止。

最初は別のキーボードで端末へ`b`だけ送ります。送信前から物理Nを押し続け、約30秒間離さず、`BEGIN`から`END`までの全ログを保存してください。`b`はC0（XIAO D10）を選び、FIX_HIZ→FIX_LOW→SCAN0→SCAN100→SCAN1000→SCANHIZを順番に実行します。`REPORT`の`COUNTS`は各行・各列で論理1を読んだ回数、`mask`は一度でも1になった列です。Nを押した期間にR2/C0が増えれば、P0.29までの信号は届いています。どの条件でも増えなければ、Nのダイオード～ソケット～XIAO D3経路またはXIAO接合を疑います。`FAULT`や`REFUSED`が出たら再配線せず、そのログを保存します。

## ピン対応

R0=D1/P0.03、R1=H=D2/P0.28、R2=N=D3/P0.29、R3=D6/P1.11。列C0=D10/P1.15、C1=D9/P1.14、C2=D8/P1.13、C3=D7/P1.12、C4=NFC2/P0.10。ここで基板上のダイオードD3とXIAO端子D3は別物です。起動時は全列Hi-Z、終了・USB切断・`x`・異常検出で全列Hi-Zへ戻ります。NFCピンがGPIO化されていない場合、他列LOWや全列走査は安全のため拒否します。UICRやフラッシュ設定は変更しません。

## 注意

出力readbackは接合や過電流を完全に保護する機能ではありません。電力サージ、発熱、焦げ臭さがあれば直ちにUSBを抜いて中止してください。通電中の抵抗・導通・ダイオード測定、信号線の電源/GNDへの短絡は行わないでください。ADC欄は電圧測定値ではありません。必要なら停止後にUSBを抜き、DMMで3.3V/GNDを測定します。
