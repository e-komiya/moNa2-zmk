# moNa2右 COROPIT診断 v3

XIAO nRF52840に書き込む、USBシリアル専用の一時診断ファームウェアです。通常のキー入力・マウスカーソル・Bluetoothは動きません。設定領域を消去する操作はありません。終了後は普段の右手用UF2を書き戻してください。実機での検証は未実施です。

## 配線と安全

- 対象は右側のみ。バッテリーは外し、電源はUSBだけを使います。BAT+修理は本診断の対象外です。
- 配線変更・はんだ付け・抵抗測定は必ずUSBも抜いた状態で行います。
- P0.09の線を4番・5番など電源端子へつないだまま起動しないでください。未接続の線の先端は絶縁します。番号は四角いパッドを1とするものですが、表裏で左右が反転します。
- この診断はCS=P0.09、SCLK=P0.05、SDIO=P0.04、MOTION=P0.02を使います。COROPITの2番=CSはroBa公開基板とCOROPITの互換性説明に基づく対応で、COROPIT自身の回路図での確認ではありません。接続位置が不明なら写真で確認してから開始します。
- 起動時は上記GPIOを入力にします。s/pで出力を開始します。読戻し確認は電流制限・過電圧保護ではありません。
- 部品が熱い、異臭がする場合は直ちにUSBを外してください。通電中に基板を金属上へ置かないでください。

## 書き込みと最初の操作

1. バッテリーを外す。USBを抜いて配線位置と隣接端子へのはんだブリッジを確認する。未接続の線は先端を絶縁する。
2. 右XIAOをUSBデータケーブルでPCへつなぐ。
3. 右基板のリセットボタンを素早く2回押す。WindowsにXIAOのUSBドライブが現れることを確認する。不明な端子同士を短絡してリセットしない。
4. `mona2-right-trackball-diag-v3.uf2`をそのドライブへコピーする。コピー後にドライブが消え、再起動する。
5. Windowsのデバイスマネージャーで「ポート(COMとLPT)」を開き、XIAOのCOM番号を確認する。Tabbyなどのシリアル端末からそのCOMへ接続する。設定は115200、8データビット、パリティなし、1ストップビット、フロー制御なし。DTRを有効にする。他のアプリで同じCOMを開かない。
6. `MONA2-TRACKBALL-DIAG-v3 READY`が出れば書き込み確認完了。表示がない場合は通常のPCキーボードで `?` を送る。Enterは不要。

## 一括診断

配線確認が済んだ状態で実施します。プローブ・テスターは使用しません。

1. COROPITを通常のホルダー・ボール付き状態にする。USB以外の電源はつながない。
2. PC側のシリアル端末を選択し、**普段使っている別のキーボード**で半角小文字 `s` を1回入力する。Enter不要。moNa2側のSキーでは操作できない。
3. `INIT OK; POLL 60s`が出たら、最初の約5秒はボールに触らない。
4. ボールを左右へ約10秒、次に前後へ約10秒ゆっくり転がす。続いて触らず停止を待つ。レンズ単体を指で擦らない。
5. 開始から60秒で自動停止する。途中停止はPCキーボードの `x`。`FAULT` / `REFUSED` / `initialization failed` が出たらそこで止め、配線を変えずログを報告する。
6. `READY`から`STOP`までをコピーして報告する。「ボールを動かしたか」「P0.09線の接続先」も添える。
7. 診断終了後はUSBを抜く。STOP後もセンサーには電源が供給され、低消費電力状態へ戻す保証はない。

## 同じ書き込みで使えるコマンド

| PC側から送る文字 | 動作 |
|---|---|
| s | 配線バイアス・ID・リセット・OBS観測・書込み確認・強制Run比較。比較条件合格時のみ移動量の60秒記録 |
| p | 配線バイアス確認とID5回のみ、終了後GPIOを入力へ戻す |
| i | GPIOとNFC設定を表示。停止中の浮いた端子の0/1だけで短絡判定しない |
| r | 60秒記録中にID/REV/OBS/PERFを読む |
| v | 移動フレームごとの詳細表示を切り替える |
| 1 / 2 | 停止中に低速 / 比較用高速を選ぶ。初期値は低速 |
| x | 停止してセンサー用GPIOを入力へ戻す |
| ? | メニュー |

通常はsだけで十分です。pや再試験でも応答しない場合、配線を闇雲につなぎ替えません。開始前IDが安定しなければ初期化書込みを行わない設計なので、応答なしだけでセンサー故障とは断定できません。

## ログの読み方と限界

- `NFC_GPIO=0`: P0.09がNFC設定。開始を拒否し、UICRを書き換えません。
- `PULL ... down=0 up=1`: 弱い内部抵抗で電位が変化した。センサーまでの導通を保証しません。拒否は外部抵抗による場合もあります。
- `PROBE_RESULT valid=5/5`: 製品ID=3eを5回読めた。少なくともID応答が安定したことを示します。
- `INIT OK`: 強制Runでの自己診断・設定読戻しが通過した。標準起動手順や通常ZMKでの成功は証明しない。
- `SELFTEST_TIME`: OBSクリア後、約50/200/1000/3000msに読んだ値。最後の読値の下位4ビットがfの場合だけ合格とする。連続読取り自体の影響は除外できないため、時間変化だけで内部故障を断定しない。
- `WRITE_CHECK`: 通常設定RUN_DOWNSHIFT(1b)へ04、05を順に書き、読値と比較する。これは揮発性設定であり、レーザー制御・OTP・自己診断制御レジスタへの試験書込みは行わない。
- `WRITE_RESTORE`: 元のRUN_DOWNSHIFT値へ戻して確認した結果。停止指示や通信異常では復元よりGPIO入力化を優先するため、途中停止後はUSBを抜いて電源を切る。
- `SUMMARY selftest_last=0 write_readback=1`: 最後の自己診断判定は不合格だが、この設定レジスタの書込み読戻しは成功。センサー全体の正常や故障は確定しない。
- `SUMMARY ... write_readback=0`: 書込み試験または復元が確認できない。具体的な期待値・読値を含めて報告する。
- `RUN_BEFORE` / `RUN_WRITE`: 元のPERFORMANCE・OBS・MOTIONと、PERFORMANCE=fdの書込み読戻し。強制Runは通常の省電力設定であり、レーザー保護解除ではない。
- `RUN_TIME`: 強制Run指定後600ms待ち、OBSをクリアして約50/200/1000/3000msで状態を観測する。MODE=0はRun、1はRest1、2はRest2、3はRest3。SQUAL、シャッター生値、画素最大/平均/最小値は参考値で、単独で部品故障とは判定しない。MOTION読み取りには状態をクリアする副作用がある。
- `LSR_FAULT=1`: センサーがレーザー関連異常を報告した。比較を打ち切り、保護解除やレーザー制御レジスタの書換えはしない。部品故障・電源問題の区別には別の証拠が必要。
- `LP_VALID`: MOTIONレジスタのレーザーパワー有効フラグ。電源電圧の測定値ではない。
- `RUN_RESTORE`: 元のPERFORMANCEへ復元した読値。キャンセル・通信異常時は復元よりGPIO入力化を優先するため、USBを抜く。
- `RUN_SUMMARY baseline=0 forced_run=1`: 標準条件では不合格、強制Run条件では通過。初期化条件への依存を示すが、修理完了とは判定しない。
- 強制Runの書込み・復元、最後のOBS下位4ビット=fかつMODE=0、レーザー異常フラグなし、設定読戻しが揃った場合だけ60秒の移動測定へ進む。それ以外は数秒でSTOPとなる。
- `sum_dx/sum_dy`: 移動量の累積。往復で相殺されるので`motion_frames`も見る。
- `irq_low_samples/irq_edges_sampled`: MOTION端子の観測。短いパルスを取り逃す場合があります。割込みに依存せず移動量を読み出します。
- `SQUAL`: 表面の読み取り状態の参考値。単独で良否判定しません。
- このファームはZMKや無線経路を通さないため、成功しても通常ファームの設定・Bluetooth・左右通信まで正常とは証明しません。
- 電源電圧は測定しません。必要時に別途テスターで確認します。BAT+と充電系は診断しません。
